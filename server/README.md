# Catstronauts - server

The starting point of the `server` code for Odyssey Lift-off I course.

From this directory, run `npm install` and then `npm start` to start the GraphQL API at
http://localhost:4000. Set the `PORT` environment variable to use a different port.
Run `npm run dev` to restart the server automatically when source files change, or
`npm run build` to compile the TypeScript source into `dist/`.
